## Background

OSDI '26 shows a shift from single-kernel optimization to full-stack LLM operations. Long-context serving, heterogeneous MoE and RL training, data pipelines, online observability, energy, SLOs, and silent-error handling are all treated as coupled systems problems.

## Methodology

| Theme | Papers | Main mechanism |
| --- | --- | --- |
| Long-context and memory | [Strata](https://www.usenix.org/conference/osdi26/presentation/xie-zhiqiang), ECHO, No Buffer No Bottleneck, Simple Is Better, [Prism](https://www.usenix.org/conference/osdi26/presentation/yu-shan) | GPU-assisted I/O, lossless prefetch, zero-copy KV movement, multiplicative request scheduling, and memory ballooning across co-served models. |

### Key Design Choices

- Treat memory traffic and scheduling latency as first-order costs, especially for long context and disaggregated systems.
- Make parallelism elastic: stage boundaries, expert placement, RL roles, and serving layouts can change at runtime.
- Close the loop with telemetry and correctness signals instead of optimizing only average throughput.

## Experiment

| Paper / group | Reported result from the official abstract |
| --- | --- |
| Strata | Up to 5x throughput over vLLM-LMCache and 3.75x over TensorRT-LLM, without hurting short-context performance; deployed in production. |
| Prism | Production deployment across 10K+ GPUs; memory ballooning unifies spatial and temporal multi-LLM sharing. |
| EcoServe | 1.96x-2.51x goodput gains on 32-GPU L20 Ethernet for reported 30B/70B settings; competitive on H100/NVLink/InfiniBand. |
| Revisiting Pipeline Parallelism | Predictive/greedy chunking and delay scheduling outperform tensor parallelism for Qwen2.5 14B/32B on four A100 40GB GPUs. |
| WLB-style reliability systems | Official abstracts emphasize fleet-scale evidence, including 35M GPU hours for SDC detection and production tracing/diagnosis. |

For the remaining papers, the conference abstracts establish the mechanism and evaluation target but do not expose a single comparable number in the schedule page. The linked presentation pages are the authoritative next read.

## Limitation

- Many OSDI '26 systems are operational or production papers; public numbers may omit cost, failure-rate, or workload-selection details.
- Adaptive schedulers can trade mean throughput for tail latency, energy, or determinism.
- Results for MoE, RL post-training, and long-context caching depend strongly on model architecture and request mix.
