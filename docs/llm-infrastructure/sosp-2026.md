## Background

SOSP '26 makes LLM infrastructure look increasingly like an operating system: it emulates thousands of GPUs, switches MoE layouts, manages encrypted inference memory, coordinates agentic streams, stores model deltas, and verifies the CUDA/runtime boundary. The official accepted list is paired with a public preprint index; some titles changed between the two, so both names are retained where useful.

## Methodology

| Theme | Papers | System idea and evidence |
| --- | --- | --- |
| Training and emulation | PrismLLM, TensorHub | Slice a large execution graph and replay virtual ranks; treat existing rollout replicas as a copy-free store for immutable weight versions. |
| Serving and inference | ACDC, Beyond Utilization, Cerium, Moebius, LLM-42, MeshRT, Janus, SANDHI, Voice Context, SystemX | Offline batching, energy-aware sharing, encrypted inference, live TP/EP switching, determinism, wafer runtime, multi-model placement, model merging, voice context, and global control planes. |
| Agents and data | AgileLog, YoloFS, SkVM | Continuous log forks, staged/undoable filesystem mutations, and capability-based skill compilation. |
| Storage, profiling, verification | TStore, LMTracer, Model2Kernel | Tensor-centric model compression, graph-embedded profiling, and model-aware CUDA memory-safety verification. |

### Key Design Choices

- Preserve one logical model while changing placement or parallelism, avoiding expensive engine restarts.
- Make model state a first-class storage object: tensors, KV cache, weights, context, and execution traces have explicit lifecycle policies.
- Constrain AI control with typed validation, verify-rollback, symbolic execution, or capability boundaries.

## Experiment

| System | Headline result from public abstract/preprint |
| --- | --- |
| PrismLLM | 0.58% average iteration-time error; <0.01% peak GPU-memory error; emulates up to 8192 GPUs with <1% physical GPUs. |
| Moebius | On 8x H200 serving Qwen3-235B-A22B, matches the better static layout, improves RL rollouts by 1.16x-1.25x, switches in 215-434 ms, and uses 2.4% memory overhead. |
| Cerium | Executes encrypted Llama3-8B inference across GPUs; reports 7.5 ms bootstrapping and 134 s end-to-end inference in the public preprint. |
| TensorDex/TStore | On 2,890 Hugging Face models, reduces storage footprint by 70.5%; compression/decompression throughput reaches 22.9/28.4 GB/s. |
| Janus | On 768 devices and 45.6M requests, reports 0.97-1.0 SLO attainment and 24% device-hour savings in its official artifact. |
| Model2Kernel | Finds 353 previously unknown CUDA memory bugs with nine false positives in public evaluation. |

## Limitation

- Five accepted papers do not expose camera-ready text; they are tracked in the source-status page, excluded from the required note set by user decision, and not summarized from titles alone.
- Encrypted inference, wafer-scale runtimes, and production serving rely on specialized hardware or private traces.
- Agent and LLM-guided control systems reduce risk through constraints, but their coverage is bounded by the policy/schema surface.
