# Cluster Performance Modeling

Papers on variability-aware performance modeling, tail-latency analysis, and scheduling insights for large-scale distributed training clusters.

## Research Areas

- Probabilistic performance modeling for distributed training
- Tail-latency and straggler analysis in GPU clusters
- Parallelism-topology co-design and critical-path attribution
- Variability-aware scheduling and cluster-level optimization
- Runtime trace analysis and simulation-driven planning
